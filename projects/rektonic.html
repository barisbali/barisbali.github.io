REKTONIC: TASK & HABIT TRACKER

AI-Powered Minimalist iOS Habit Tracker with Fluid Vector Physics

SYSTEM ARCHITECTURE OVERVIEW

Rektonic was engineered to eliminate productivity friction by pairing raw telemetry feedback with fluid visual metaphors. The core engine utilizes custom animatable SwiftUI vector paths that simulate dynamic fluid mechanics inside a virtual container: incomplete tasks add volume to the container, while completion empties it. The objective is achieving zero volume — a fully resolved system state.

CORE TECHNICAL CAPABILITIES

  • Gesture-Driven Interface: Low-latency gesture recognizers optimized for single-handed mobile navigation.
  • On-Device AI Decomposition: FoundationModels integration to hierarchically break down complex objectives into micro-actions without sending telemetry off-device.
  • High-Reliability Persistence: Robust CoreData schema layer ensuring thread-safe local data sync and zero latency during high-frequency writes.
  • Tactile Visual Haptics: Custom CoreHaptics engine providing real-time physical confirmation upon objective resolution.

ENGINEERING CHALLENGES & OPTIMIZATIONS

The primary technical challenge was maintaining 60 FPS fluid dynamic rendering in SwiftUI. This was accomplished by implementing custom AnimatableData vector curves and offloading frame-by-frame trigonometric computations. On-device LLM inference was memory-bound; resolved by creating lightweight prompt-quantized execution threads.
